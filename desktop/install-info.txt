对话手记 Windows 版（本地自用）

本软件免费使用，不提供任何充值、代充、收款或支付功能，也不提供 API Key。
所有 API Key 由模型供应商或其官方 API 平台提供，需要用户自行注册、申请并管理。
模型调用、额度购买和充值费用由用户自费承担。免费额度与费用以供应商官方信息为准。
软件中的“获取 Key”和“余额/充值”入口只打开供应商官方网页，不在软件内办理付款。

安装后可以从桌面或开始菜单直接打开。不需要 Node.js、npm 命令或本地网页服务。

要求 Windows 10 1809 / Windows 11，64 位，以及 Microsoft Edge WebView2 Runtime。
这台电脑已经有 WebView2。本安装包不捆绑整个浏览器。

安装包不包含个人 API Key 或聊天记录。首次打开有引导教程，可从“聊天设置”随时重看。
请在“聊天设置”选择平台、阅读 Key 获取教程并配置 API，
也可以点击“导入旧版 API 配置”，自行选择原项目的 .env 文件。
Key 使用 Windows 当前用户加密存储，不会返回给页面或写入聊天备份。

新版记录独立保存在此应用中，不会自动读取原浏览器或手机的记录。
更新安装和卸载程序不删除用户数据；不要自行删除本机应用数据目录。

这是未购买商业代码签名证书的自用安装包，Windows 可能显示未知发布者。
