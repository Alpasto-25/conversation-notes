## 数据升级与回退

IndexedDB 从 v2 升级到 v3，升级事务为原记录生成 notebookIndex；v1 数据保留原迁移路径。摘要与正文增删改放在同一事务，列表只读摘要和当前一份正文。迁移失败回滚由自动测试覆盖。

旧版 v2 应用不能连接已升级的 v3 数据库。正式试用前先保留旧包及数据副本，不能把旧包覆盖到新库上当作无损回退。本次浏览器及独立真机验收版均使用合成数据，未读取、迁移或覆盖正式应用的私人数据。

分析版本、撤销和多场景内容会增加存储和备份体积。保存失败继续阻止不安全切换，并提示重试；应定期导出备份。

- Windows 原生离线检查 **180 通过**，前端和安装/便携包构建成功；负载隐私审计通过。
- Android 文件检查 **18**、备份分块传输 **9** 项通过；APK 构建、签名校验及 **19 项包内容审计**通过。正式应用没有覆盖安装，独立真机验收结果见后文。
- 隔离 Chromium、纯合成记录、所有外网请求拦截：原生 Ctrl+V 和预览/只保存零分析请求；120 条记录定位第 91 条、收藏/编辑/撤销恢复；备注和人工状态不改模型事件。
- 加密备份导出、错口令拒绝、恢复副本与原内容一致；TXT/MD 脱敏、全部图片 ZIP 导出并由 Python 标准库校验 CRC、页序及 PNG 尺寸。所有导出物都是合成数据。
- 两次分析后恢复第一次结果，两个运行账本均保留、无新请求。补充模拟 503 后基础结果保留，新的补充运行及未知费用标记落盘；首个基础请求等待中切换手记，任务总数与未知费用保留，回来显示继续提示。

- 30000 条、约 326 万字符的 Worker 合成解析与立即取消通过；解析过程中主线程定时器可运行。另通过实际文件控件导入约 1.3 MB、12000 条合成消息，选择末 10 条；三昵称归并为两人及日期过滤通过，零模型请求。
