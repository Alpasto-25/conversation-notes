# 表达方式与潜台词

此功能默认关闭，按需在 API 配置页开启。关闭时只做基础分析；开启后可选择以下组合：

- **仅 DeepSeek**：DeepSeek 完成基础判断、表达方式与潜台词解读。
- **Jev + DeepSeek**：Jev 完成基础分析及表达方式、潜台词状态和依据判断，DeepSeek 根据这些结论写解释。DeepSeek 不得修改 Jev 的判断；Jev 失败时不自动改用 DeepSeek 判断。

配置页只显示所选组合需要的表单。两个平台分别使用自己的 Key，分别计费。开启开关或切换组合不会自动发起模型请求。

## 结果与显示

表达方式描述这句话如何表达，不代表建议用户采用同样的方式回复。潜台词先判断为有依据（`supported`）、无明显潜台词（`none`）或证据不足（`uncertain`）。字面已能解释的普通消息不强制生成隐藏含义，明确拒绝或边界不能解读为反向邀请。

仅有依据的消息生成最多 80 字的简短解释。聊天页与分享图片完整换行，详情加粗主要情绪、意图、表达方式和潜台词，并保留原文依据；内部概率与置信度不在用户详情中展示。

## 请求与恢复

Jev 使用支持的选择与独立概率题；DeepSeek 的双模型解释只接受潜台词文本，返回额外判断字段会被拒绝。仅 DeepSeek 使用状态优先的结构，同一次请求完成判断与解释。

批次超限时缩小目标范围，保留完整可见语境及已完成结果。失败后可只补充表达方式与潜台词；合法的零请求结果仍可保存，不能伪造供应商用量。

新增结果使用独立版本、模型和上下文指纹复用。旧记录保持可读，打开、重载或切换场景不自动补算。基础分析继续保留自己的消息只能使用当时已有历史的因果约束。

重新分析需用户确认，覆盖当前场景的分析及用量，原结果不可恢复；聊天原文和其他场景保留。取消不清理结果，也不调用模型。

## 实现位置

组合路由见 `shared/analysis-mode.ts`；Jev 判断见 `shared/semantic-judgment.ts`；请求、校验与恢复见 `shared/semantics.ts`。界面使用 `src/SemanticSwitch.tsx`、`src/ChatMessage.tsx` 和 `src/SemanticDetail.tsx`，遵循 [现有界面规范](../UI_STYLE.md)。
