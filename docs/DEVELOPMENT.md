# 开发说明

使用 Node.js 22.12+，在源码目录运行 `npm ci` 和 `npm run dev`。

验证：`npm test`、`npm run build`、`npm run test:desktop`。

构建：`npm run build:desktop`（Windows）或 `npm run build:android`（Android）。本机构建不会自动公开发布。
