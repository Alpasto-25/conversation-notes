# 对话手记

[English](README.en.md)

用于双人文字对话的本机分析工具，支持日常、朋友、家庭、工作、客户及恋爱场景，提供情绪、意图、表达质量和下一步建议。

1.1.3 新增对话片段图片 / TXT 分享、手记批量管理与移动、可调电脑侧栏及分析用量诊断，并修复分享图片标签遮挡。界面沿用已有设计，DeepSeek 仅提供 Flash；更新检查不调用模型，也不自动安装。

> **首先感谢原作者 [FerryCorleone](https://github.com/FerryCorleone) 及贡献者的卓越贡献。** 原项目 [crush-monitor](https://github.com/FerryCorleone/crush-monitor) 的原创构想、对话解析和 Jev 分析实现是本扩展的基础。本项目是非官方 Fork，不代表原作者背书；原 MIT 许可完整保留，详见[致谢与贡献归属](ACKNOWLEDGEMENTS.md)。

## 使用

在“外观模式”中选择跟随系统、浅色或暗色，选择会保留。默认开启启动更新检查，发现有效新版本时弹窗提醒；可稍后处理，也可关闭当前构建的提醒，更新入口红点仍保留。应用不自动下载或安装，更新检查不调用模型。

1. 首次打开按引导选择 API 平台，填写该平台的 Key；设置中提供获取教程和官方计费入口。
2. 选择分析场景，粘贴对话或导入文本文件，确认哪个昵称是自己。
3. 点击“开始分析”，查看结果；追加新聊天可继续分析。

“对话文件夹”按场景和聊天对象分类。新建保留旧记录，切换直接恢复原文及已保存分析，不再次消耗模型额度；导入也可先只保存、不分析。

文件夹可整理名称、对象与场景、排序并记住展开状态。整份手记删除后进入回收站，可恢复；单条消息删除需确认，会清除该手记依赖旧上下文的分析，不自动重算。电脑最大化时界面随窗口扩展。

本地待验收的手记管理更新：导入默认填入当前空手记，不再额外留下空白记录；已有聊天、场景结果或另一份草稿会保留。文件夹和回收站支持多选移入回收站、恢复及确认后彻底删除，操作不调用模型；手机删除或取消后保留当前文件夹、搜索与展开状态。电脑可拖动侧边栏右边界调宽并记住宽度，也支持方向键、Home / End 和双击恢复默认。加号按钮居中；手机下拉框和工作空间菜单可再次点击原按钮收起。导入确认页支持选择本次分析模型，配置保存完成前禁用开始分析。修改尚未发布。

本地待验收的移动与分享更新：可点按移动图标选择文件夹，也可长按手记拖入目标文件夹；悬停展开、边缘滚动，手机原有左滑入口继续可用，多选也可一起移动。移动保留原文、草稿和各场景分析。分享直接进入全屏聊天预览，长按开始多选，点按选择或取消；图片沿用原聊天的气泡、头像和分析标签，长内容分页。TXT 面向交给其他 AI 深入分析，保留所选原文、完整逐条分布与原始概率。回收站支持批量恢复、永久删除和确认后清空。常用操作统一为图标，保留操作提示与读屏名称。手机支持系统分享或保存，电脑可保存文件。旧 Pro 配置按 Flash 使用，历史模型标记保留。以上仍只提供本地测试，不发布。

1.1.2压缩了情绪 / 意图标签和“我的表达 / 下一步”功能条的留白，文字样式保持不变。点击功能条右上方的全屏按钮可展开聊天记录及已有分析，情绪、意图、回复评价和底部功能条保留，仍可点击查看完整解读；再次点击恢复正常布局，并回到进入全屏前的阅读位置。全屏不重载聊天、不丢失草稿、不自动调用模型，支持手机返回键和 Esc 退出。

支持微信、QQ 和常见 WhatsApp 文字格式；其他来源可整理为：

```text
我：明天下午一起讨论方案吗？
对方：可以，三点见。
```

仅支持双人文字对话，不读取聊天软件账号或数据库。图片、语音需先转为文字。

“版本与更新”确认有新版后显示红点，可手动检查并跳转下载页；自动检查在启动时及运行期间每 6 小时执行，可关闭。关闭提醒不会清除红点，不会自动下载安装，退出后不后台运行。

## API 与费用

支持 [TypeSafe](https://console.typesafe.ai/keys)、[Vercel AI Gateway](https://vercel.com/d?to=%2F%5Bteam%5D%2F%7E%2Fai-gateway%2Fapi-keys)、[OpenRouter](https://openrouter.ai/settings/keys) 和 [DeepSeek 官方 API](https://platform.deepseek.com/api_keys)，Key 必须来自对应平台。

1.1.2新增 DeepSeek Flash 和聊天页“模型”选择器。各平台的 Key 在电脑/手机各自加密保存一次，之后切换模型或切回已配置平台无需重复填写；旧版 Jev 配置继续可用。切换本身不调用模型，不清除已有分析；新模型用于后续主动分析。不同模型的速度、结果及费用不同，实际响应还受网络和供应商负载影响。

DeepSeek Flash 使用 JSON 模式，每题列出完整候选键，避免事件与意图选项混用。模型返回带候选键的相对权重，由应用统一归一化为概率与评分，避免长记录分析依赖模型手算概率合计或数数组位置。缺失问题、带非零权重的未知候选、全零或非法权重仍会拒绝。可定位到单题的问题只以 JSON 模式补全一次，保留同批已通过答案，实际用量累计计入；对方多消息批次补全后只剩一条未完成时，再自动重评该条一次，其他情况报错并保留已完成进度。零权重占位不影响评分，旧版返回格式继续兼容。手机空状态卡片取消内部滚动与聊天按钮预留空间；短屏滚动整页，导入后继续使用原有聊天滚动区。

原网页版可在 `.env` 设置 `JEV_PROVIDER=deepseek` 和 `DEEPSEEK_API_KEY`；`JEV_MODEL` 可选 `deepseek-flash` 或 `deepseek-v4-pro`。保留原有配置变量，接口地址固定，无需填写 Base URL。

本地待验收修改：DeepSeek 请求按稳定规则、聊天原文、动态目标排序；候选和评分说明统一为可复用题目模板，三端共用序列化实现。同一提示词类型的前两个正常请求串行完成后再并发，不增加预热调用。自己的表达逐条只提供当时已有的历史；对方情绪、意图和事件合批使用上下文。历史不变的逐条结果可在本机直接复用，模型、场景或有效上下文变化会使对应缓存失效。本次分析用量入口显示供应商返回的输入、输出、缓存命中及未命中 tokens，并统计本机复用条数；未提供的字段显示未知。供应商的实际缓存命中、费用与分析质量仍需亲测，修改尚未发布。

用量诊断补丁：用量随一次分析保存模型和起止时间，恢复时标为上次分析用量；切换模型保留旧解读，点击按当前模型重新分析才会调用 API，整份结果与续跑按平台和模型隔离。DeepSeek 明细逐条记录返回模型、请求 ID、任务/批次、system 指纹、时间及真实 tokens，单题补全独立列出，不记录聊天原文或 Key。内部重试计入请求数，未返回的用量保持未知；软件按一次分析统计，官网按模型与时段汇总。

对方批次的本地测试优化：目标消息 ID 在任务中只发送一次，返回使用短题号，再由共享适配层还原为原题号；完整评分模板、候选和所有非零权重保留，未限制候选数量。定向补全保留原短题号及完整规则，避免答案移到别的消息。自己的表达与总览请求保持原有字节及缓存版本；对方逐目标缓存使用新的协议版本，已保存的解读不会自动收费重算。用量弹窗增加按模型、任务、规则指纹的加权汇总，以及补全题数、缺失/格式不符计数。Flash 继续为 DeepSeek 默认项，Pro 由用户选择。实际 token、补全频率及解读质量仍待亲测，尚未发布。

Flash 返回恢复的本地测试修订：带候选名称的权重列表与纯候选键映射可按同样的严格权重规则读取；重复候选、未知非零候选、全零和位置数组仍拒绝。混用原题号与短题号只使对应题目失效。一次定向补全仍失败时，保留各轮完整通过的消息到本机缓存并保存已返回的用量；情绪、意图或事件缺少任一项的消息不会生成结果。用户重试只分析尚未完成的消息。逐请求明细显示校验结果、缺失/格式不符题数及安全的错误类别，不保存原始回答、推理或 Key。携带已返回用量的限流错误不会自动重跑整批。Windows 与 Android 使用相同恢复逻辑，实际 Flash 验收和发布仍由用户确认。

Flash 再次重测后的本地规则调整：对方任务的短题号模板增加明确的情绪/意图/事件用途及各自非空权重规则，不依赖短题号中已不存在的后缀。定向补全逐题列出原别名、用途、精确候选与失败类别，真假题明确要求零到一数字；正常自己的表达和总览请求字节保持不变，补全继续共用各自正常请求的 system。仅对方逐目标缓存协议更新为 other-sparse-v2，已保存的完整解读仍可继续使用。逐请求失败诊断按用途细分全零、混选项、重复候选、非法权重、错误结构、真假概率或题号冲突，只保存固定类别和题数，不保存原始字段和值。补全仍最多一次；真实返回效果待用户验收，未发布。

Flash 单条续跑验证后的本地修订：对方多消息批次一次补全后，若只有一条消息仍有格式问题且其他答案已通过，最多再请求一次该条的情绪、意图、事件；使用该条新的密集题号和原上下文，保留既有合法答案，只添加通过校验的缺失答案。不会重跑总览或整个批次；恢复仍失败、出现限流、模型改变或取消即停止。新增请求的实际用量计入本次明细，标为“单条恢复”，汇总的补全返回包含该项。正常请求、规则指纹和缓存协议保持不变。最近一次未完成分析的用量独立随手记保存，成功继续后可查看“上次未完成用量”，不会覆盖或混入本次统计。两端共享实现，真实 Flash 稳定性仍待用户亲测，未发布。

**软件免费，不提供充值、代充、收款或 Key 销售。API Key 由用户自行向供应商获取，模型调用和额度费用由用户自费承担。** 分析、示例和连接测试可能消耗额度；赠额、价格和模型权限以供应商为准。

## 隐私与说明

记录保存在本机，但分析片段会发送给所选模型供应商。仅使用有权分享的内容，勿公开 Key 或私人聊天；AI 结果仅供参考。电脑、手机和网页版数据独立，不自动同步；卸载手机应用或清理数据会删除记录及配置。
